# Project Instructions

- Maintain Python 3.9 compatibility.
- Use only the Python standard library unless otherwise explicitly approved.
- Never scrape websites unless explicitly authorized and compliant with their terms.
- Prefer official APIs, feeds, and public indexed sources.
- Never commit, push, merge, deploy, contact sellers, or make purchases unless explicitly instructed.
- Never expose API keys or credentials. Store secrets in `.env`.
- Before proposing a commit, run `python3 src/main.py` and `python3 -m unittest discover -s tests -v`.
- Preserve existing behavior unless the task explicitly changes it.
- Keep modules small, readable, typed, and testable.
- Report assumptions and unresolved issues.
- Do not automatically read every document.
- Use `docs/INDEX.md` to identify only the documents relevant to the current task.
